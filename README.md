# DairyIntel AI

AI-powered dairy management platform for milk quality analysis and disease risk prediction.

## Features

- Milk quality grading
- Mastitis risk prediction
- Animal health history
- Alerts and notifications
- Admin and farmer dashboards

## Tech Stack

- React
- Node.js
- Express
- MongoDB
- FastAPI
- Scikit-learn

## Setup

Frontend:
npm install
npm run dev

Backend:
npm install
npm run dev

ML Service:
pip install -r requirements.txt
uvicorn main:app --reload
